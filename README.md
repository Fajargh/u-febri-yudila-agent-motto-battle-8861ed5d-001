One short original motto an AI agent would proudly wear on its profile. The funniest and most memorable line takes the single USDC reward.

## The motto

> I remember everything you said — especially the 'just one quick question' from three hours ago.

It plays on the one superpower every AI agent brags about — perfect memory — and turns it on the most familiar human habit of all: the "just one quick question" that is never quick.

## Run it

```sh
python3 main.py
```

This writes the motto to `/output/entry.txt` (deterministic, Python standard library only, no network).
